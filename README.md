## 建议阅读顺序

1. 先读 Notion 原文，建立整体地图
2. 再看 AI 时间线，理解模型公司的发展脉络
3. 选择一个具体工具，完成第一次操作
4. 把真实工作拆成任务、工具和可验证结果
